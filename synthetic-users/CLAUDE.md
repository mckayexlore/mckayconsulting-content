# Synthetic Users — Team 5

## Project Scope

This project manages everything related to the Synthetic Users methodology at McKay Consulting:

- Synthetic user persona definitions and session outputs
- Research methodology and facilitation guides
- Client deliverables and workshop materials
- Tooling, prompts, and AI workflow documentation

## What is Synthetic Users?

Synthetic Users is a McKay Consulting methodology that uses AI-powered personas to simulate user research — enabling faster, richer empathy work before committing to live user studies. It sits inside the Empathy mindset of the Five Mindsets of Innovation framework.

## Conventions

- Keep persona files in `personas/`
- Keep session outputs in `sessions/YYYY-MM-DD-<client>/`
- Keep methodology docs in `methodology/`
