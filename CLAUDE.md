# McKay Consulting — Website Content Project (Team 6)

## Project Scope

This project manages the McKay Consulting website content and business operations:

- **Website copy** — EN/DA translation files for mckayconsulting.dk
- **CRM** — contact list and outreach tracking (`crm/contacts.csv`)
- **HTML content** — page-level markup for WordPress

## Out of Scope: Synthetic Users → Team 5

**Synthetic Users** is a separate project. It lives in **Team 5**.

If asked anything related to Synthetic Users — methodology, personas, research output, tools, session notes, or any related work — **do not attempt to answer or reason from this project**. Instead, tell the user:

> "Synthetic Users content is in Team 5. Please switch to that project to work on this."

This boundary prevents fabrication. Team 6 holds no Synthetic Users context.

## Conventions

- CSV edits: preserve all 18 column headers exactly as-is
- Translation files: always maintain both EN and DA columns; do not remove EN_NEW or EN_SHORT
- Commits: use the format `CRM: <action>` for contact changes, `Website: <action>` for copy changes
